Custom high-performance & fully customizable Elementor widgets and interactive sliders.

== Description ==

PNS Addons for Elementor is a comprehensive suite of premium, highly customizable widgets and sliders designed specifically for the Elementor page builder.

### Included Features & Widgets:
* **Interactive Sliders & Carousels**: Modern Slider, Accordion Slider, Member, Video Popup Cards.
* **Content & Layout Widgets**: What We Do Grid, Sticky Project, Progress Timeline, Promo Banner Card, Footer, HTML Table.
* **Grid & Showcase Widgets**: Card Grid, Logo Carousel, Dual Heading, Testimonial.
* **Interactive Components**: PNS FAQ Accordion, Marquee Text, Animated Button, Image Hover Cards, Timeline.

== Installation ==

1. Upload the `pns-addons-for-elementor` directory to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Open any page in Elementor and drag any of the 19 widgets from the "PNS Addons" category into your layout.

== Frequently Asked Questions ==

= Does this require Elementor? =
Yes, Elementor Page Builder must be installed and activated on your WordPress site.

= Are all widgets customizable? =
Yes! You can customize typography, colors, padding, layout, and content directly within the Elementor editor panel.
