Custom high-performance & fully customizable Elementor widgets and interactive sliders.

== Description ==

Elementor Addon is a comprehensive suite of premium, highly customizable widgets and sliders designed specifically for the Elementor page builder.

### Included Features & Widgets:
* **Interactive Sliders & Carousels**: Modern Slider, Accordion Slider, Premium Card Carousel, Video Popup Cards.
* **Content & Layout Widgets**: What We Do Grid, Sticky Stacking Projects, Alternating Process Timeline, Promo Banner Card, Floating Card Premium Footer, Custom Responsive HTML Table.
* **Grid & Showcase Widgets**: SDG Alignment Grid, Core Services Grid, Brand Partners Gallery, Elegant Custom Title, Client Testimonials Grid.
* **Interactive Components**: Infinite Marquee Ticker Bar, Animated Button, Image Hover Cards, Timeline.

== Installation ==

1. Upload the `elementor-addon` directory to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Open any page in Elementor and drag any of the 20 widgets from the "Custom Widgets" category into your layout.

== Frequently Asked Questions ==

= Does this require Elementor? =
Yes, Elementor Page Builder must be installed and activated on your WordPress site.

= Are all widgets customizable? =
Yes! You can customize typography, colors, padding, layout, and content directly within the Elementor editor panel.
